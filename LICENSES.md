### ⚠️ Flag: Pillow binary wheels
The official Pillow wheels (checked: `pillow-13.0.0.dist-info/sboms`) contain **libimagequant (GPL-3.0-or-later)**, statically
linked into `PIL/_imaging*.so`, and **FriBiDi (LGPL-2.1-or-later)**, dynamically loaded. vector-press never calls the
code paths that use them (Image.quantize with libimagequant, complex text layout), but they are *distributed* inside the wheel.
- Using the engine on your own machine/server: no distribution → no obligation.
- **Shipping an app that bundles Pillow commercially**: build Pillow from source without libimagequant, e.g. on macOS
  `brew install libjpeg libpng libtiff webp little-cms2 freetype` then
  `pip install --no-binary pillow pillow==13.0.0` (libimagequant is only linked if it is installed; check with
  `python -c "from PIL import features; print(features.check('libimagequant'))"` → `False`).
  scikit-image requires Pillow, so Pillow cannot simply be removed.
